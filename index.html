Construindo uma API: Sistema de Controle e Manutenção de Máquinas

Visão Geral do Projeto

Este projeto é uma API RESTful completa. Um sistema real não guarda apenas as máquinas, ele precisa saber quem realizou uma ação e manter um histórico do que foi feito.

Vamos construir três tabelas interligadas:

  • Usuários: Quem opera o sistema (técnicos, engenheiros).
  • Máquinas: O equipamento físico em si.
  • Manutenções: O registro do conserto. Esta tabela conecta o Usuário à Máquina através de Chaves Estrangeiras (Foreign Keys).

A Stack Tecnológica e o "Porquê"

  • FastAPI: Framework ultra-rápido para receber requisições web e gerar documentação automática (Swagger).
  • SQLAlchemy (ORM): Traduz código Python para banco de dados. Permite mudar do SQLite para o PostgreSQL no futuro mudando apenas uma linha.
  • Alembic: O "controle de versão" do banco de dados. Cria scripts automáticos quando adicionamos novas colunas.
  • Pydantic: O "segurança" da API. Valida se os dados enviados pelo usuário estão corretos antes de chegarem ao banco.
  • SQLite: Banco de dados em um único arquivo local. Perfeito para desenvolvimento sem configurações complexas.

Passo 2: Conexão com o Banco (database.py)

A aplicação precisa saber onde o banco está. Criamos um "Motor" (engine) que aponta para o arquivo maquinas.db. A SessionLocal será nossa área de trabalho: abrimos para salvar algo e fechamos logo depois.

from sqlalchemy import create_engine
from sqlalchemy.orm import sessionmaker, declarative_base

SQLALCHEMY_DATABASE_URL = "sqlite:///./maquinas.db"

# check_same_thread é exigência do SQLite no FastAPI
engine = create_engine(
    SQLALCHEMY_DATABASE_URL, connect_args={"check_same_thread": False}
)

SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)

Base = declarative_base()

def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()

Passo 3: As Tabelas e Relacionamentos (models.py)

O SQLAlchemy usa classes Python para criar tabelas. A mágica acontece usando ForeignKey (que diz ao banco quem é o pai) e relationship (que carrega os objetos automaticamente para o Python).

from sqlalchemy import Column, Integer, String, Boolean, ForeignKey, DateTime
from sqlalchemy.orm import relationship
from datetime import datetime
from database import Base

class Usuario(Base):
    __tablename__ = "usuarios"

    id = Column(Integer, primary_key=True, index=True)
    nome = Column(String, nullable=False)
    email = Column(String, unique=True, index=True, nullable=False)
    
    manutencoes = relationship("Manutencao", back_populates="usuario")

class Maquina(Base):
    __tablename__ = "maquinas"

    id = Column(Integer, primary_key=True, index=True)
    nome = Column(String, nullable=False)
    marca = Column(String, nullable=False)
    numero_serie = Column(String, unique=True, index=True, nullable=False)
    em_operacao = Column(Boolean, default=True)
    
    manutencoes = relationship("Manutencao", back_populates="maquina")

class Manutencao(Base):
    __tablename__ = "manutencoes"

    id = Column(Integer, primary_key=True, index=True)
    descricao = Column(String, nullable=False)
    data = Column(DateTime, default=datetime.utcnow)
    
    maquina_id = Column(Integer, ForeignKey("maquinas.id"), nullable=False)
    usuario_id = Column(Integer, ForeignKey("usuarios.id"), nullable=False)

    maquina = relationship("Maquina", back_populates="manutencoes")
    usuario = relationship("Usuario", back_populates="manutencoes")

Passo 4: Validação de Dados (schemas.py)

O Pydantic cria "filtros". Separamos os dados de criação (Create) da resposta da API (Response). Na Manutenção, instruímos a API a devolver os dados do técnico e da máquina juntos (aninhados).

from pydantic import BaseModel
from typing import Optional
from datetime import datetime

# --- SCHEMAS DE USUÁRIO ---
class UsuarioBase(BaseModel):
    nome: str
    email: str

class UsuarioCreate(UsuarioBase): pass

class UsuarioResponse(UsuarioBase):
    id: int
    class Config: from_attributes = True

# --- SCHEMAS DE MÁQUINA ---
class MaquinaBase(BaseModel):
    nome: str
    marca: str
    numero_serie: str
    em_operacao: bool = True

class MaquinaCreate(MaquinaBase): pass

class MaquinaResponse(MaquinaBase):
    id: int
    class Config: from_attributes = True

# --- SCHEMAS DE MANUTENÇÃO ---
class ManutencaoBase(BaseModel):
    descricao: str
    maquina_id: int
    usuario_id: int

class ManutencaoCreate(ManutencaoBase): pass

class ManutencaoResponse(ManutencaoBase):
    id: int
    data: datetime
    maquina: Optional[MaquinaResponse] = None
    usuario: Optional[UsuarioResponse] = None

    class Config: from_attributes = True

Passo 5: Criar o Banco Fisicamente (Alembic)

Configuramos o Alembic para ler o models.py e gerar o banco. Execute no terminal:

alembic init alembic

Abra o arquivo alembic.ini e altere:

sqlalchemy.url = sqlite:///./maquinas.db

Abra alembic/env.py, importe os modelos e altere o target:

import sys

from database import Base

# Altere target_metadata para:

Gere e aplique a migração no terminal:

alembic revision --autogenerate -m "Criacao das tabelas"
alembic upgrade head

Passo 6: A API e as Regras de Negócio (main.py)

Aqui expomos as URLs. Note as regras de negócio: verificamos se o email ou número de série já existem, e ao registrar uma manutenção, validamos se a máquina e o técnico são reais.

from fastapi import FastAPI, Depends, HTTPException
from sqlalchemy.orm import Session
from typing import List
import models, schemas
from database import get_db

app = FastAPI(title="Controle de Manutenção")

# === USUÁRIOS ===
@app.post("/usuarios/", response_model=schemas.UsuarioResponse)
def criar_usuario(usuario: schemas.UsuarioCreate, db: Session = Depends(get_db)):
    if db.query(models.Usuario).filter(models.Usuario.email == usuario.email).first():
        raise HTTPException(status_code=400, detail="Email já cadastrado.")
    novo = models.Usuario(**usuario.model_dump())
    db.add(novo)
    db.commit()
    db.refresh(novo)
    return novo

# === MÁQUINAS ===
@app.post("/maquinas/", response_model=schemas.MaquinaResponse)
def criar_maquina(maquina: schemas.MaquinaCreate, db: Session = Depends(get_db)):
    if db.query(models.Maquina).filter(models.Maquina.numero_serie == maquina.numero_serie).first():
        raise HTTPException(status_code=400, detail="Série já cadastrada.")
    nova = models.Maquina(**maquina.model_dump())
    db.add(nova)
    db.commit()
    db.refresh(nova)
    return nova

# === MANUTENÇÕES ===
@app.post("/manutencoes/", response_model=schemas.ManutencaoResponse)
def registrar_manutencao(manu: schemas.ManutencaoCreate, db: Session = Depends(get_db)):
    if not db.query(models.Maquina).filter(models.Maquina.id == manu.maquina_id).first():
        raise HTTPException(status_code=404, detail="Máquina não encontrada.")
    if not db.query(models.Usuario).filter(models.Usuario.id == manu.usuario_id).first():
        raise HTTPException(status_code=404, detail="Usuário não encontrado.")

    nova_manu = models.Manutencao(**manu.model_dump())
    db.add(nova_manu)
    
    # Atualiza o status da máquina
    db.query(models.Maquina).filter(models.Maquina.id == manu.maquina_id).update({"em_operacao": True})
    
    db.commit()
    db.refresh(nova_manu)
    return nova_manu

@app.get("/manutencoes/", response_model=List[schemas.ManutencaoResponse])
def listar_manutencoes(db: Session = Depends(get_db)):
    return db.query(models.Manutencao).all()
